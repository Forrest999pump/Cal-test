# เครื่องคิดเลข (Calculator) 🧮

โปรเจ็คเครื่องคิดเลขอย่างง่ายที่เขียนด้วย **Python** รับค่าตัวเลขและเครื่องหมายจากผู้ใช้ แล้วแสดงผลลัพธ์การคำนวณในรูปแบบที่อ่านง่าย

## วิธีการรันโปรแกรม

### ความต้องการของระบบ
- Python 3.10 ขึ้นไป (รองรับ `match/case`)

### คำสั่งรัน

```bash
python3 calculator.py
```

### ตัวอย่างการใช้งาน

```
========================================
     เครื่องคิดเลข (Calculator)
========================================
ป้อนตัวเลขที่ 1: 10
ป้อนเครื่องหมาย (+, -, *, /): +
ป้อนตัวเลขที่ 2: 5
----------------------------------------
  ผลลัพธ์: 10 + 5 = 15
========================================
```

---

## ฟีเจอร์

- **รองรับ 4 การดำเนินการ**: บวก `+`, ลบ `-`, คูณ `*`, หาร `/`
- **รองรับทั้ง Integer และ Float**: ป้อนได้ทั้ง `10` และ `3.14`
- **ป้องกันหารด้วยศูนย์**: แสดงข้อความแจ้งเตือนแทนการ crash
- **Validation**: ตรวจสอบค่าที่ป้อนทุกครั้ง ถ้าผิดรูปแบบจะให้ป้อนใหม่
- **แสดงผลสวยงาม**: ผลลัพธ์อยู่ในรูปแบบ `ตัวเลข1 เครื่องหมาย ตัวเลข2 = ผลลัพธ์`

---

## โครงสร้างการทำงาน (Inputs → Process → Output)

| ขั้นตอน | รายละเอียด |
|---------|-----------|
| **Inputs** | รับตัวเลขที่ 1, เครื่องหมาย, ตัวเลขที่ 2 พร้อม validation |
| **Process** | ใช้ `match/case` เลือกการคำนวณที่เหมาะสม |
| **Output** | แสดงผลในรูปแบบ `10 + 5 = 15` |
